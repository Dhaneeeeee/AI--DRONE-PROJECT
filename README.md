🚁 AI Drone Technology for Human Detection in Disaster
 📌 Project Overview
This project focuses on developing an AI-powered drone system that can detect and locate humans during natural disasters such as earthquakes, floods, and landslides. The system uses computer vision and voice recognition to improve rescue operations.
---
 🎯 Objectives
- Detect trapped humans using AI-based object detection (YOLOv8)
- Provide real-time monitoring through dashboard
- Enable voice recognition support
- Improve emergency rescue response time
---
 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- YOLOv8 Model
- Python (for AI model)
- Computer Vision
---
 📂 Project Structure
- `index.html` – Main homepage  
- `dashboard.html` – Monitoring dashboard  
- `body-detection.html` – Human detection module  
- `voice-recognition.html` – Voice detection feature  
- `script.js` – JavaScript functionality  
- `styles.css` – Styling  
- `yolov8n.pt` – YOLO AI model  

---
🚀 How to Run the Project
1. Clone the repository
2. Open `index.html` in browser
3. Run AI model (if using backend with Python)
4. Access dashboard for monitoring
